# AkiraMakira

AkiraMakira — desktop-приложение для Windows с локальными ИИ-персонажами на базе Qwen.

## Главное: Ollama отдельно устанавливать не нужно

Приложение само скачивает и запускает portable-версию Ollama внутри своей папки данных. Это не системная установка: не добавляется в PATH и не регистрируется в Windows как отдельная программа.

При первом запуске нажми **«Подготовить ИИ»**. Приложение загрузит:
- локальный движок Ollama для Windows x64 (текущий официальный архив может занимать около 1.6 ГБ);
- выбранную модель Qwen 3.5 (например, `qwen3.5:4b`, около 3.3–4.0 ГБ по каталогу моделей).

Нужен интернет только для первоначальной загрузки. После загрузки генерация работает локально, без API-ключа и без отправки переписки во внешний ИИ-сервис. Учитывай, что файлы движка и модели занимают несколько гигабайт.

## Возможности
- Персонажи с именем, описанием, характером, манерой речи и собственными правилами поведения.
- Загрузка аватаров PNG/JPG/JPEG/WEBP.
- Отдельная история сообщений каждого персонажа.
- Формат диалога с именами персонажей и действиями в *звёздочках*.
- Локальная модель Qwen через встроенный portable runtime.
- Создание, редактирование и удаление персонажей.

## Требования
- Windows 10 22H2 или новее, x64.
- Интернет и несколько гигабайт свободного места при первой подготовке ИИ.
- Для готовой EXE-сборки Python и Ollama устанавливать не нужно.

## Как запустить готовую сборку
1. Открой GitHub Actions: https://github.com/bs9973866-png/akiramakira/actions
2. Открой успешный запуск **Build Windows app** и скачай artifact `AkiraMakira-Windows`.
3. Распакуй архив и запусти `AkiraMakira.exe`.
4. Нажми **«Подготовить ИИ»** и дождись загрузки движка и модели.
5. После завершения выбери персонажа и начни общение.

## Сборка из исходников
Для разработчика:
1. Установи Python 3.10+.
2. Запусти `install.bat`.
3. Запусти `start.bat` для режима разработки.
4. Запусти `build_exe.bat`, чтобы создать `dist\AkiraMakira\AkiraMakira.exe`.

## Локальные данные
Профили, аватары, переписки, portable-движок и модель хранятся в:
`%APPDATA%\AkiraMakira\`

Удаление EXE-папки не удаляет эти данные. Для полного удаления данных удали `%APPDATA%\AkiraMakira\` вручную.

## Примечания
- Модель загружается отдельно и не включена в EXE.
- Скорость зависит от процессора, видеокарты и объёма оперативной памяти.
- Персонажи предназначены для безопасного дружеского общения и творческих сцен.
