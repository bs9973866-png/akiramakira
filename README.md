# AkiraMakira

AkiraMakira — desktop-приложение для Windows с локальными ИИ-персонажами на базе Qwen через Ollama.

## Возможности
- Персонажи с именем, описанием, характером, манерой речи и собственными правилами поведения.
- Загрузка аватаров PNG/JPG/JPEG/WEBP.
- Отдельная история сообщений каждого персонажа.
- Выразительный формат диалога: имя персонажа, реплики и действия в *звёздочках*.
- Локальный Qwen без API-ключа.
- Создание, редактирование и удаление персонажей.
- Настройки модели и загрузка моделей из интерфейса.

## Требования
- Windows 10 22H2 или Windows 11.
- Python 3.10+ (для запуска из исходников).
- Ollama для Windows.
- Интернет нужен только для первоначального скачивания Ollama и модели. Сам чат работает локально.

## Быстрый запуск
1. Установи Ollama: https://ollama.com/download/windows
2. Установи Python 3.10 или новее: https://www.python.org/downloads/windows/
3. Запусти `install.bat`, чтобы установить зависимости.
4. Запусти `start.bat`.
5. В приложении нажми «Скачать модель» и выбери `qwen3.5:4b`. Для слабого ПК можно выбрать `qwen3.5:2b`.
6. Когда модель загрузится, выбери её и общайся.

Ollama обычно предоставляет локальный API на `http://localhost:11434`. AkiraMakira не требует API-ключа и не отправляет историю диалогов во внешний сервис.

## Сборка EXE
После установки зависимостей запусти `build_exe.bat`. Готовая папка приложения появится в `dist\AkiraMakira\`. Сборка использует PyInstaller в режиме one-folder для более надёжного запуска Qt.

## Данные
Профили, аватары и переписки хранятся локально в:
`%APPDATA%\AkiraMakira\`

Удаление приложения не удаляет эту папку. Для полного удаления данных удали её вручную.

## Примечания
- Модель загружается отдельно и занимает место на диске. Размер зависит от выбранного варианта.
- Скорость генерации зависит от процессора, видеокарты и объёма оперативной памяти.
- Персонажи предназначены для безопасного дружеского общения и творческих сцен.
